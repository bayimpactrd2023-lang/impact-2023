# R2 Upload 401 Unauthorized Fix

## Problem
When uploading images in the Admin panel, you get a **401 Unauthorized** error:
```
PUT https://...supabase.co/functions/v1/server/r2/highlights/... 401 (Unauthorized)
```

## Root Cause
The Edge Function (`server`) is missing the `SUPABASE_ANON_KEY` environment variable, which is required to verify the JWT authentication token.

## Solution

You have **2 options** to fix this:

---

### Option 1: Quick Dashboard Fix (Recommended - 2 minutes)

1. Go to [Supabase Dashboard](https://app.supabase.com)
2. Select your project
3. Go to **Edge Functions** in the sidebar
4. Click on the **"server"** function
5. Go to the **"Secrets"** tab
6. Add these environment variables:

   | Secret Name | Value | Where to find |
   |-------------|-------|---------------|
   | `SUPABASE_ANON_KEY` | Your anon key | Project Settings → API → `anon/public` key |
   | `SUPABASE_URL` | `https://your-project-ref.supabase.co` | Project Settings → API → URL |
   | `R2_WORKER_URL` | Your Cloudflare Worker URL | Cloudflare Dashboard |
   | `R2_WORKER_TOKEN` | Your Worker token | Cloudflare Dashboard |

7. Click **Save**
8. Redeploy the function (or it may auto-deploy)

---

### Option 2: CLI Deployment (If you have Supabase CLI)

1. Open terminal in project root
2. Run the deployment script:
   ```bash
   ./scripts/deploy-edge-function.sh itwdgcubpfuuacumgylb
   ```
3. Enter the required values when prompted:
   - `SUPABASE_ANON_KEY` - Get from Dashboard → Project Settings → API
   - `R2_WORKER_URL` - Your Cloudflare Worker URL
   - `R2_WORKER_TOKEN` - Your Cloudflare Worker token

---

## Verify the Fix

1. Hard refresh your browser (Ctrl+Shift+R)
2. Log out and log back in to the Admin panel
3. Try uploading an image again
4. Check browser console - you should see successful upload messages

---

## Still Getting 401?

If you still see 401 after setting the secrets:

1. **Check if you're logged in** - The upload requires an active admin session
2. **Check Edge Function logs** in Supabase Dashboard → Edge Functions → server → Logs
3. **Verify the secrets** are set correctly (no extra spaces)
4. **Redeploy the Edge Function** after setting secrets

---

## Where to Find Your Keys

### Supabase Dashboard
- Project Settings → API → Project API keys
- `anon/public` = SUPABASE_ANON_KEY
- `service_role` = INTERNAL_SERVICE_ROLE_KEY (for admin operations)

### Cloudflare Worker (if using R2)
- Cloudflare Dashboard → Workers → Your R2 Worker
- Worker URL = R2_WORKER_URL
- Worker Token = R2_WORKER_TOKEN (set in Worker environment)

---

## What Changed

The Edge Function now logs detailed auth diagnostics. Check the Edge Function logs in Supabase Dashboard to see:
- If environment variables are set
- If the token is being parsed correctly
- If the token is expired
- Detailed error messages

This will help identify exactly what's causing the 401 error.
