Setup Instructions

  1. Enable "Public Development URL" in Cloudflare R2 dashboard
  2. Copy the generated URL (e.g., https://pub-XXXXX.r2.dev)
  3. Add VITE_R2_PUBLIC_URL to your environment variables
  4. Restart your development server
  5. Refresh this page
